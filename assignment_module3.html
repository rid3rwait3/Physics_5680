Task 2: Run kfold validation to choose hyperparameters¶

We will use kfold validation to pick help us choose hyperparameters in the SVC method. We will focus on these two hyperparameters:

  • gamma: Gamma determines the influence of individual training examples on the decision boundary. The gamma parameter defines how far the influence of a single training example reaches, with low values meaning 'far' and high values meaning 'close'.
  • kernel: The kernel refers to the kernel function used by SVC. Kernel functions are used to map the input data points into a higher-dimensional space where the separation between the two classes becomes easier. This allows SVC to solve complex non-linear problems as well.

We will use a dictionary to store the hyperparameters we want to try - ours will have 7 entries, with different combinations of gamma and kernel.

Here we want to loop over the kfolds (just like we did in the in-class version), but we want to calculate the average "test" recall (accuracy) and precision over the folds.

You can get this by pulling the macro average recall out of the results_test dictionary.

Store these in a dictionary called "avg_recall_results". The key should be (gamma,kernel), and you can store it in the loop like this:

    avg_recall_results[(gamma,kernel)] = avg_recall_weighted_test

from collections import defaultdict


best_gamma = "scale"
best_kernel = "poly"

estimator = SVC(gamma=best_gamma, kernel=best_kernel, random_state=42)

kfolds = 4
skf = StratifiedKFold(n_splits=kfolds)

recalls = []
precisions = []
recall_by_class = defaultdict(list)
precision_by_class = defaultdict(list)

for train_idx, test_idx in skf.split(X, y):
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]

    estimator.fit(X_train, y_train)
    y_pred = estimator.predict(X_test)

    recalls.append(recall_score(y_test, y_pred, average="macro", zero_division=0))
    precisions.append(precision_score(y_test, y_pred, average="macro", zero_division=0))

    report_dict = classification_report(y_test, y_pred, output_dict=True, zero_division=0)
    for digit in report_dict.keys():
        if digit.isdigit():  # skip 'accuracy', 'macro avg', etc.
            recall_by_class[int(digit)].append(report_dict[digit]["recall"])
            precision_by_class[int(digit)].append(report_dict[digit]["precision"])

avg_recall = np.mean(recalls)
avg_precision = np.mean(precisions)

print("Best Hyperparameters → gamma:", best_gamma, "kernel:", best_kernel)
print("Average Recall across folds:", avg_recall)
print("Average Precision across folds:", avg_precision)

print("\nPer-Class Averages:")
for digit in sorted(recall_by_class.keys()):
    print(f"Digit {digit}: Recall={np.mean(recall_by_class[digit]):.3f}, Precision={np.mean(precision_by_class[digit]):.3f}")

You give it an estimator (like SVC) and a list of paremeters to search over, and it handles all of the stpes to evaluate the estimator using cross validation. It returns scoring metrics for all of the aremneter combinations, as well as the overall best estimator.
